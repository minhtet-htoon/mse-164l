# MSE 164L Monday 3:00 Group 2

## How To:

Install conda environment:

```bash
conda env create -f environment.yml
```

Add Materials Project API key to .env

```dotenv
API_KEY=your_mp_api_key
```

Add data files, make sure it follows the format

```csv
two_theta,intensity
10,1
10.05,2
```

Open the Jupyter Notebooks

```bash
jupyter lab
```
